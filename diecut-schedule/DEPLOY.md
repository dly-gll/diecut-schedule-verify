# 模切 APS V5 部署说明

## 1. 文件
- server.js：V5 APS 后端
- index.html：V5 前端
- package.json：依赖
- .env.example：生产配置示例

## 2. 安装
```bash
npm install
NODE_ENV=production node server.js
```

## 3. V5 APS 核心
- 多目标评分：交期、急单、优先级、换模、负荷均衡、物料就绪、完工时间
- 生产中任务硬锁
- 已完工任务保留
- 滚动重排
- 已完工记录可编辑实际完工时间
- 修改完工时间后自动重排同设备尚未开始的后续任务

## 4. 备份
正式环境升级前先备份 data.db。

V5.1 排程规则更新：
1. 有有效交货/出货需求日期的订单，优先于无交期订单。
2. 有交期订单内部按交期从近到远，再使用 V5 多目标评分。
3. 无交期订单统一后置。
4. 正在生产的订单继续保持锁定，不参与自动重排。
